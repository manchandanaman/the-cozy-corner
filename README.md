☕ The Cozy Corner – Cafe Website

A responsive cafe website built using HTML5, CSS3, and JavaScript. Users can explore coffee and bakery products, search the menu, and manage their shopping cart.

🌐 Live Demo

View Live Website

✨ Features
Responsive cafe website design
Dynamic product menu
Search products by name or category
Add and remove products from cart
Increase and decrease product quantities
Automatic cart total calculation
LocalStorage integration to save cart data

🛠️ Technologies Used
HTML5
CSS3
JavaScript
Browser LocalStorage
